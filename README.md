# 🛒 Enterprise E-Commerce REST API Production Engine

A modular, robust, and secure E-Commerce RESTful backend engine engineered utilizing the MVC design architecture pattern via Node.js, Express, and MongoDB/Mongoose layer.

## 🚀 Key Architectural Features
- **Strict MVC Separation Layout**: Distinct isolated directories handling specific business layers cleanly.
- **Advanced Dynamic Multi-Filter System**: Fluidly combine query constraints (`search`, `minPrice`, `maxPrice`, `inStock`, `category`).
- **Server-Side Transaction Math**: Absolute calculations protected on the server to mitigate client mutation hacks.
- **Automatic Data Lifecycle Seeder**: Cascading validation data wipe and generation script execution.
- **Robust Error Catching Pipeline**: Catch and translate MongoDB operational errors securely.

## 📋 Technology Infrastructure Stack
- Runtime Engine: Node.js (v18+)
- Framework Layer: Express.js (v4.19+)
- Database Layer: MongoDB Community Server
- Object Modeling Mapper: Mongoose (v8.4+)
- Security Protection: Express-Mongo-Sanitize
